# Andrea Servin · Portafolio personal

Página de presentación de Andrea Servin, Ingeniera Informática y desarrolladora de software full stack con 5 años de experiencia, en Encarnación, Paraguay. Reúne mis proyectos, mis herramientas y mi información de contacto.

**Sitio:** https://andrea-servinm.github.io

## Qué incluye

- **Presentación** con enlaces directos a contacto, proyectos y GitHub.
- **Fondo animado** de fragmentos de código dibujado en `canvas`, que solo aparece en la parte superior y se adapta al tema claro u oscuro.
- **Proyectos** ordenados del más reciente al más antiguo, con tecnologías, estado, demo y código.
- **Sobre mí y herramientas**, agrupadas por área: frontend, backend, bases de datos relacionales y NoSQL, automatización e IA, e infraestructura.
- **Contacto** por correo, GitHub y LinkedIn.
- **Modo claro y oscuro** automático, según la preferencia del sistema.
- **Responsiva** para celular, tablet y escritorio.
- **Accesible:** foco visible con teclado, contraste adecuado y respeto por la preferencia de movimiento reducido (el fondo queda estático).

## Tecnologías

HTML, CSS y JavaScript puros, sin frameworks ni dependencias. Solo se cargan las tipografías Bricolage Grotesque e Instrument Sans desde Google Fonts.

## Estructura

```
andrea-servinm.github.io/
├── index.html    # contenido y estructura
├── styles.css    # estilos, colores y modo oscuro
├── script.js     # fondo animado de código
└── README.md
```

## Cómo verla en tu computadora

Abre `index.html` en el navegador. No hace falta instalar nada.

## Cómo agregar un proyecto

En `index.html`, dentro de la sección `#proyectos`, copia un bloque `<article class="proj">` y edita el título, la descripción, las etiquetas y los enlaces. Para mantener el orden de más reciente a más antiguo, colócalo al principio de la lista.

## Cómo cambiar los colores

Los colores y las tipografías están como variables al inicio de `styles.css`, en `:root`, con su versión para el modo oscuro.

## Publicación

El sitio se publica con GitHub Pages desde la rama `main`, carpeta raíz. Cada cambio que se sube al repositorio se refleja en el sitio en uno o dos minutos.
